# LDAP

LDAP (Lightweight Directory Access Protocol) directory service bilan ishlash va query qilish protokoli.

Labda `visual.local` directorysi query qilinib user accountlar enumeration qilingan.

- `Base DN`: `dc=visual,dc=local`
- `sAMAccountName`: AD logon name attribute
- `objectClass`: object turini bildiruvchi attribute
