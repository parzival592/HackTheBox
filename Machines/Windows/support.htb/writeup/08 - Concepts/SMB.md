# SMB

SMB (Server Message Block) Windows network file/resource sharing protokoli.

Labda `445/tcp` ochiq bo‘lgan. Authenticated enumeration `ADMIN$`, `C$`, `IPC$`, `NETLOGON`, `SYSVOL` sharelarini ko‘rsatgan. Nmap SMB message signing enabled va required ekanini bildirgan.
